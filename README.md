# Portfolio Projet : Assurances dommages

Une webapp et un microservice web (API) pour l'évaluation de réclamations d'assurances dommages  

### Résumé
- **WebApp**
  - Côté serveur
- **Microservices**:
  - API REST
  - Modélisation et documentation
  - Service logique
  - Service collecte (intégration)
  - Service DAO
  - Service autentification

### Stack technique
- Langage: **Python** / Flask
- Documentation: **Swagger**
- Base de données: **MongoDB**
- Autentification: **JWT**
- Environnements: **Pycharm**, **GitHub**
